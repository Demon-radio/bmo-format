# BMO RFC-0009 — Conformance (v0.9.0-alpha, DRAFT)

Status: **DRAFT**, depends on RFC-0001..0008. "We read BMO" is a claim;
this document turns it into a checklist with files.

## 1. Levels (cumulative — each includes everything above it)

| Level | Must pass | Proves |
|---|---|---|
| **Reader** | §2 container suites | opens goldens, rejects corruption with the RIGHT code |
| **Writer** | + build goldens byte-identical | deterministic encoding, sorted directory, valid chains |
| **Round-trip** | + preservation suites | unknown ancillary/critical rules, `ext`/role/rev survival |
| **Structure** | + model suites | R1–R6, envelope defaults keep v0.1 files valid |
| **Domain** | + text/graphics/sheet/deck suites | body vocabularies, addresses, membership, deps contract |
| **Security** | + crypto suites | framing, tag discipline, canonical-hash stability |

One command runs everything portable: `python tests/run_all.py`
(exit 0 = all green; Rust suites run separately in CI with toolchains).

## 4. Negative catalog (must-fail inputs, exact codes)

BAD_MAGIC, HEADER/CHUNK/PAYLOAD/FOOTER_CRC_MISMATCH, NO_VALID_FOOTER,
TRUNCATED, DUPLICATE_OBJECT_ID, DIRECTORY_UNSORTED, UNKNOWN_CRITICAL,
UNKNOWN_EXTENSION, UPGRADE_REQUIRED, INCOMPATIBLE_MAJOR, LIMIT_EXCEEDED,
AUTH_FAILED, DOC_ID_MISMATCH, TXN_MISMATCH, ROOT_MISMATCH, CORRUPT,
STRUCTURE_INVALID, DANGLING_REF. A reader that fails with the wrong code
fails the suite — diagnostics are part of the contract.

## 5. Fuzz + interop (standing requirements)

* Fuzz corpus seeds in `tests/fuzz/` (structure-aware: mutate headers,
  CRCs, lengths, CBOR); no panics/unbounded allocs on any input.
* Interop (RFC-0008 §4): second implementations MUST publish A→B→A
  matrices; DOCX/XLSX/PPTX compat percentages are measured by converter
  suites, never asserted in prose.
